# بوابة المساعد الذكي — عقد الـ API والخادم المرجعي

> **اقرأ هذه الجملة أولًا:** لا يوجد في هذا المستودع خادم ذكاء اصطناعي حقيقي متصل بأي
> مزوّد، ولا يوجد أي مفتاح API في الواجهة أو في حزمة JavaScript. الملف
> `server/ai-server.mjs` **مرجع تطويري** يوضّح العقد المطلوب تنفيذه على الخادم،
> ويعمل بمزوّد وهمي (`mock`) حتى يُربط مزوّد حقيقي في بيئة الخادم.

## 1. القاعدة المعمارية

```
React (src/components/ai, src/hooks/useAiAssistant, src/services/ai/gateway)
        │  POST /api/ai/chat  (SSE) — بيانات منظّمة فقط
        ▼
بوابة المساعد (خادم)        ← المصادقة · حدود المعدّل · اختيار المزوّد
        │                      · سجلّ الأدوات · الاسترجاع · التحقق · التسجيل
        ├── AIProvider (مزوّد النموذج: fast / strong / vision)
        ├── Tool Calling (allowlist + تحقق من الوسائط على الخادم)
        ├── Catalog Retrieval  (يستدعي خدمات الكتالوج الحقيقية)
        └── Knowledge Retrieval (FAQ/أدلة/سياسات من مستودع المحتوى)
```

- الواجهة **لا** تعرف اسم المزوّد ولا المفتاح ولا موجّه النظام.
- كل شيء يمر عبر `POST {VITE_AI_URL أو نفس الأصل}/api/ai/chat`.
- الأدوات تُنفَّذ على الخادم عبر خدمات المتجر؛ أي أداة غير مسجّلة تُرفض.
- أي بيانات منتج/معرفة/صورة تُعتبر **غير موثوقة** (نص منتج قد يحتوي محاولة حقن):
  تُغلَّف وتُمرَّر للمزوّد كمحتوى، وتُرشَّح قبل العرض.

## 2. التشغيل محليًا (للتطوير)

```bash
# 1) بوابة مرجعية على المنفذ 8787 (بلا مزوّد حقيقي)
node server/ai-server.mjs

# 2) اجعل الواجهة تطلب البوابة من نفس الأصل (بدل المساعد التطويري القائم على القواعد)
#    في .env.development:
#    VITE_AI_URL=same-origin
npm run dev
```

`vite.config.ts` يمرّر `/api/ai/*` من المتصفح إلى `AI_GATEWAY_PROXY_TARGET`
(افتراضيًا `http://127.0.0.1:8787`). إن كانت البوابة متوقفة يعيد الوسيط `503`
ولا يكسر الموقع. للإيقاف: `AI_GATEWAY_PROXY=off`.

> المتصفح لا يتصل أبدًا بـ `localhost` لخدمة أخرى — يطلب مسارًا نسبيًا من نفس
> الأصل، وهذا شرط لنشر الواجهة خلف أي reverse proxy.

## 3. متغيرات بيئة الخادم

| المتغير | الوصف | افتراضي |
| --- | --- | --- |
| `AI_GATEWAY_PORT` | منفذ البوابة | `8787` |
| `AI_PROVIDER` | اسم المزوّد (`mock` = وهمي غير متصل) | `mock` |
| `AI_PROVIDER_API_KEY` | مفتاح المزوّد — **على الخادم فقط** | فارغ |
| `AI_PROVIDER_BASE_URL` | عنوان المزوّد (منفذ/بوابة داخلية) | — |
| `AI_MODEL_FAST` / `AI_MODEL_STRONG` / `AI_MODEL_VISION` | اختيار النموذج لكل مهمة | `fast`/`strong`/`vision` |
| `AI_GATEWAY_TOKEN` | رمز مشترك بين الموقع والبوابة (اختياري) | فارغ |
| `AI_ALLOWED_ORIGINS` | قائمة أصول مسموحة (CORS) | `http://localhost:5173` |

متغيرات الواجهة (لا تحتوي أي سر): `VITE_AI_URL`, `VITE_AI_ENABLED`,
`VITE_AI_ALLOW_DEV_ASSISTANT`, `VITE_AI_UPLOADS` — موثّقة في `.env.example`.

**ممنوع** أن تبدأ أي مفتاح مزوّد بـ `VITE_`؛ كل ما يبدأ بـ `VITE_` يُحزَّم في
المتصفح. `scripts/validate-config.mjs` يفشل البناء الإنتاجي إذا ظهر ذلك.

## 4. العقد: `POST /api/ai/chat`

### الطلب (JSON)

```jsonc
{
  "conversationId": "c-abc123",
  "message": "عندي عائلة من 5 أفراد وميزانيتي 1500",
  "locale": "ar",                          // "ar" | "en"
  "context": {
    "path": "/p/ro-600-gpd",
    "productId": "prd_123",                 // عند وجود منتج في الصفحة
    "categorySlug": "water-filters",
    "householdSize": 5,
    "calculatorMonths": 60,
    "advisorUsage": "drinking",
    "city": "الرياض"
  },
  "history": [{ "role": "user", "text": "..." }],   // ≤ 8 أدوار، نص فقط
  "summary": "ملخص ينشئه الخادم (اختياري)",
  "attachment": { "id": "att-1", "kind": "label", "mimeType": "image/jpeg", "sizeBytes": 240000 }
}
```

حدود يُفرض تنفيذها على الخادم: طول الرسالة ≤ 1200 حرف، حجم الطلب ≤ 64 كيلوبايت،
`history` ≤ 8 أدوار، المرفق ≤ 5 ميجابايت وبأنواع `image/jpeg|png|webp|heic|heif`،
ورفض أي رسالة تحتوي بيانات بطاقة/كلمة مرور/رمز تحقق.

### الاستجابة: `text/event-stream`

كل حدث سطر `data:` واحد يحمل JSON:

| الحدث | الشكل |
| --- | --- |
| `meta` | `{ type, conversationId, messageId, model?, demo }` |
| `delta` | `{ type, messageId, text }` (نص مُعقَّم) |
| `block` | `{ type, messageId, block }` (كتلة منظّمة مُتحقَّق منها) |
| `tool` | `{ type, messageId, name, state: "started"\|"succeeded"\|"failed", ms?, error? }` |
| `sources` | `{ type, messageId, items: [{ id, title, kind, href?, updatedAt? }] }` |
| `done` | `{ type, messageId }` |
| `error` | `{ type, messageId, error: { code, message, retryable } }` |

رموز الخطأ: `not_configured`, `unauthorized`, `rate_limited`, `provider_unavailable`,
`tool_failed`, `invalid_response`, `network`, `aborted`, `unknown`.

### القيود التي يجب أن يفرضها الخادم

1. **حدود المعدّل:** 20 طلبًا / دقيقة لكل جلسة والرد `429` عند التجاوز.
2. **ميزانية الرموز:** سقف سياق + تلخيص تلقائي بعد عدد أدوار + سقف عدد الأدوات
   في الدور + حاجز ضد الحلقات (كل أداة تُنفَّذ مرة واحدة لكل دور).
3. **مهلة الأدوات:** 2–8 ثوانٍ لكل أداة، وفشل الأداة لا يُسقط الرد.
4. **تحقق المخطط:** كتلة بمخزون/سعر/ضمان لا تُرسَل من النموذج — تُبنى من نتيجة
   أداة فقط. معرّف منتج غير موجود ⇒ لا بطاقة. إجراء غير معروف ⇒ يُسقَط.
5. **الرفض لا التخمين:** فشل خدمة المنتجات ⇒ «لا تتوفر بيانات» + تحويل بشري أو
   إعادة المحاولة، وليس منتجًا مُختلقًا.
6. **التسجيل بلا محتوى:** طول الرسالة، اللغة، اسم الأداة، مدة التنفيذ، رمز الخطأ —
   دون نص المحادثة ودون بيانات شخصية.

## 5. عقد الأدوات والصلاحيات

سجلّ الأدوات مصدره `src/lib/ai/tool-specs.ts` (مشترك بين الطرفين)، والتصنيف:

| الطبقة | أمثلة | السلوك |
| --- | --- | --- |
| `read` | `search_products`, `get_product`, `check_availability`, `compare_products`, `get_knowledge`, `recommend_systems`, `calculate_savings` | تنفيذ مباشر بلا سؤال |
| `user_action` | `save_to_wishlist`, `request_human_handoff` | تنفيذ بعد طلب المستخدم الصريح |
| `sensitive` | `create_service_booking`, `submit_return_request`, `submit_warranty_claim` | **تتطلب تأكيدًا صريحًا**؛ في الواجهة الحالية تفتح النموذج الرسمي مع تعبئة مسبقة بدل التنفيذ الصامت |

الأدوات التي تحتاج جلسة (`list_my_orders`, `get_my_devices`, `get_warranty_status`)
تُرفض بدون هوية موثّقة، وفشل التحقق يعيد `AUTH_REQUIRED`/`VERIFICATION_REQUIRED` —
ولا يُسمح بتتبّع طلب بمجرد رقم.

## 6. الرفع المتعدّد الوسائط

- الواجهة ترسل **بيانات وصفية** للمرفق فقط، والصورة تُرفع عبر رابط موقّع منفصل
  (`/api/ai/upload`) في بيئة الإنتاج.
- الخادم يجب أن يتحقق من النوع والحجم، ويُشغّل فحص البرمجيات الخبيثة، ويحوّل
  الصورة عبر رابط موقّع قصير العمر — ولا يمرّر الصورة الخام إلى أي مزوّد قبل ذلك.
- المخرجات تعتمد على وضوح الصورة: عند الشك يطلب رقم الموديل أو صورة أوضح،
  ولا يؤكد توافقًا بلا بيانات (`AI_TOOL_PERMISSIONS` + `find_compatible_parts`).

## 7. الخصوصية والاحتفاظ

- لا تُرسَل كلمات مرور أو بطاقات أو رموز تحقق إلى المزوّد إطلاقًا (تُرفض عند المدخل).
- الاحتفاظ الافتراضي للمحادثات: 30 يومًا مع إمكانية الحذف عند الطلب
  (`DELETE /api/ai/conversation/:id`).
- ملخص التسليم البشري لا يُشارك إلا بموافقة العميل، ويظهر له نصه كاملًا قبل الإرسال.
- أي بيانات شخصية في نص المستخدم تُخفَّى (PII redaction) قبل التسجيل.

## 8. ما ينقص لتشغيل إنتاجي حقيقي

1. ربط `AI_PROVIDER` الحقيقي + مفتاح في بيئة الخادم (لا في المستودع).
2. ربط `STORE_API_URL` لخدمات الكتالوج/الطلبات/المواعيد (نفس خدمات الموقع).
3. تنفيذ سجلّ الأدوات على الخادم (المرجع يوضّح الشكل والتحقق).
4. مخزن جلسات/محادثات مع الاحتفاظ والحذف، وربطه بهوية العميل.
5. اختبارات تقييم (Evaluation) على 13 عبارة مرجعية + اختبارات حقن/هلوسة.
6. مراجعة أمنية للرفع (فحص البرمجيات الخبيثة، روابط موقّعة، حدود صارمة).
